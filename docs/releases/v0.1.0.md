# Zero Editor v0.1.0

The first downloadable release: a local macOS text editor with an English Nord interface, keyboard commands and no accounts or integrated AI.

## Highlights

- Drag tabs to reorder them or move them into a new native window.
- Split adjacent documents; the last tab splits with its previous neighbor.
- JetBrains Mono for editing and Helvetica Neue Medium for the interface.
- Command palette, context menus, regex find/replace and line:column navigation.
- Undo/redo, smart indentation and line/block editing commands.
- Syntax highlighting, line numbers, font zoom and optional whitespace markers.
- Background recovery drafts shared across windows, atomic saves and encoding preservation.

## Download and install

Download **Zero-Editor-v0.1.0-macos-arm64.zip**, extract it and move **Zero Editor.app** to Applications.

- Architecture: **Apple Silicon (arm64)**. No Intel or universal binary is included.
- Declared minimum: macOS 12. Older macOS versions have not been verified; the package was checked on the development Mac.
- Signing: **ad hoc**, without Developer ID signing or notarization. macOS may block the first launch.
- Integrity: compare the downloaded ZIP's SHA-256 hash with **SHA256SUMS.txt**.

## Known limits

Vim modal editing, LSP, project navigation and multiple cursors are not implemented.
Sessions restore all documents into one window; window geometry and split layout are not saved.
Undo history is not restored across launches. External changes are not detected before saving.

`⌘⇧D` duplicates lines; use `⌘.` for whitespace markers.
